# Disaster Tweet Classification with Machine Learning

This notebook explores and compares classical machine-learning models for classifying tweets as disaster-related or not disaster-related.

## Workflow

- Load `tweets.csv` in Google Colab and inspect the dataset and class balance.
- Clean tweet text, remove English stop words, and derive text features for analysis.
- Explore word frequencies, class-specific n-grams, and word clouds.
- Compare CountVectorizer, TF-IDF, and combined Count + TF-IDF features.
- Train Logistic Regression, Multinomial Naive Bayes, Decision Tree, and Random Forest classifiers; selected notebook sections also use GridSearchCV.
- Review accuracy and class-level precision, recall, and F1 reports.

## Data

The notebook expects `tweets.csv` with a tweet text column named `text` and a binary `target` column (`0` = not disaster-related, `1` = disaster-related). The dataset is not included. Upload it when prompted in Colab.

## Run in Google Colab

1. Open `tweets.ipynb` in Google Colab.
2. Upload `tweets.csv` when the notebook requests it.
3. Run the cells in order. Install any missing packages reported by the runtime.

The notebook exports evaluation reports for some experiments. Results can vary with data and runtime; use the outputs generated by your own run rather than assuming a fixed benchmark.
